03 / AGENT EVALUATION

Agent 评测，
看结果也看过程。

根据实际复测中整理的方法展示评测思路。原始输入、回复和媒体文件未公开，这里只呈现可复用的检查框架。

01 / 定义
先写通过标准固定输入和环境

明确每个用例的预期输出、允许的部分通过情形以及失败条件；记录模型、工具、资料范围和会话条件。

02 / 留证
分层看执行链路回复、调用、状态、成品

最终回复、实际工具调用、任务提交、状态成功和成品检查分别记录；前一层成立不自动代表后一层通过。

03 / 回归
逐用例比较变化改善、退步与持续问题

为 Bad Case 保留输入、实际输出、复现步骤和关闭标准。比较条件不一致时，只描述表现变化，不归因模型能力。

评测状态：方法来自实际复测与问题归因；原始内部证据未公开。这里不展示未经验证的通过率、提效比例或模型优劣结论。
